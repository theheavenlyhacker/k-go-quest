# Database table map

Run `npm run db:migrate` to create the schema selected by `DATABASE_SCHEMA` (default `kgo`). Alternatively, run `database/schema.sql` once in Aiven's `defaultdb`; it creates tables inside `kgo`, including migration bookkeeping. Existing `public` tables belong to the other backend and are not modified. Keep the quoted camelCase column names: they match the TypeORM entities.

| Table            | Purpose                                         | Relationships and constraints                                                           |
| ---------------- | ----------------------------------------------- | --------------------------------------------------------------------------------------- |
| jurisdictions    | LGU ownership boundary                          | Parent of schools, accounts, content and rewards                                        |
| schools          | Schools served by an LGU                        | jurisdictionId references jurisdictions                                                 |
| users            | Student, teacher, and LGU accounts              | Unique loginId, hashed passwords, nonnegative coins; students/teachers require schoolId |
| auth_sessions    | Device sessions and hashed refresh tokens       | One unrevoked session per user                                                          |
| classrooms       | Grade/section and assigned teacher              | References school and teacher                                                           |
| enrollments      | Learner class membership                        | Unique classroomId + studentId                                                          |
| content_packs    | Versioned subject/grade packs                   | References jurisdiction                                                                 |
| lessons          | Lesson text, skill identifiers, reviewed hints  | References content pack                                                                 |
| exercises        | Multiple-choice prompts and private answer keys | References lesson                                                                       |
| attempts         | Server-verified synced exercise events          | Unique studentId + clientAttemptId; references student, classroom, exercise             |
| skill_progress   | Per-skill mastery estimates                     | Unique studentId + skillCode                                                            |
| growth_snapshots | Monthly baseline/latest estimates               | Unique studentId + skillCode + month                                                    |
| rewards          | LGU catalog, price and stock                    | Nonnegative stock, positive price                                                       |
| redemptions      | Atomic spending and voucher claims              | Unique studentId + requestId; references learner, reward, claiming admin                |
| audit_events     | Security and mutation history                   | Actor and jurisdiction references                                                       |
| migrations       | TypeORM bookkeeping                             | Initial migration included in SQL export                                                |

Application IDs are UUIDs generated by the application. PostgreSQL generates createdAt. The SQL includes foreign keys, uniqueness constraints, wallet/stock checks, and indexes. Aliases and ownership IDs are pseudonymous records, not a guarantee of complete anonymization.

In the Aiven SQL editor, select the `kgo` schema or qualify queries: `SELECT count(*) FROM kgo.users;`. The application configures TypeORM's schema and each connection's search_path to the same validated identifier. It never falls back to public tables. `npm run db:check` reports connection, certificate verification, missing tables/columns, and the initial migration record. Readiness is not an exhaustive constraint/permission audit.
